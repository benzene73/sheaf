# Local client-library build

Run `npm ci` for the repository's pinned tooling, then `npm run build:primitives`. The build uses the existing esbuild and TypeScript dependencies; it does not start Phoenix, build the reference React app, install application dependencies or publish a package.

Output is the ignored `dist/` directory, regenerated on each run:

- `index.js`: browser-targeted ES2022 ESM bundle with the ten individual hook exports and aggregate `hooks` map from `src/liveview/index.ts`.
- `index.js.map`: JavaScript source map with source content.
- `types/liveview/index.d.ts` and transitive declaration files/maps: public entry types, generated by TypeScript.
- `BASE-UI-MIT.txt`: exact upstream MIT notice, also referenced in the JavaScript banner.
- `package.json`: private local ESM entry and runtime dependency manifest.
- `metafile.json` and `build-summary.json`: output/dependency inspection data.

The ESM bundle externalizes **@floating-ui/dom 1.8.0** and **@floating-ui/utils 0.2.12**. Its actual external import specifiers are `@floating-ui/dom` and `@floating-ui/utils/dom`; consumers must resolve those packages through their normal bundler. React, React DOM, Babel, Playwright and Phoenix JavaScript are not bundled or imported by this client entry. LiveSocket is supplied by the consuming Phoenix application.

After placing the local build in an application's assets or using its private local package, register its exported hooks with the existing LiveSocket `hooks` option. Keep the matching HEEx component structure and event contracts: the hooks are not arbitrary-DOM enhancers. Elixir helpers remain source under `lib/liveview_primitives/` (Components, Controls and Combobox); **there is no published Hex package or npm release**. This build is a handoff artifact, not a claim of production-ready packaging or supported application integration.

Verified at handoff: `npm run build:primitives` succeeds; importing the ESM entry exposes all ten hooks without mounting them; TypeScript accepts the generated declaration entry. Measured unminified JavaScript is **122,995 bytes**, gzip **27,031 bytes**, and source map **267,106 bytes**. These are this build's sizes, not production bundle-size estimates; future changes and consumer tree shaking/minification can change them. `dist/build-summary.json` is authoritative for subsequent builds. No browser matrix was rerun for this build-only task.
