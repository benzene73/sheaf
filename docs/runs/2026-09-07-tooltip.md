# Everyday Tooltip gate

Four paired Chromium scenarios passed 8/8 executions: keyboard focus opens,
Escape closes retaining trigger focus, blur closes, and hover/leave opens/closes.
The fixture explicitly sets delay=0, closeDelay=0 and disableHoverablePopup=true.
Provider delays, hoverable-popup pointer corridors, touch and timer races are not
part of this gate. Raw report: `artifacts/tooltip-paired-chromium.json`.

This exact upstream pin emits neither role=tooltip nor aria-describedby by
default, confirmed in rendered DOM and by source inspection. The driver records
that omission in its semantics field and uses a shared popup test ID for behavior.
LiveView adds role and description linkage as an intentional accessibility
improvement. This difference is not represented as upstream semantic parity.
