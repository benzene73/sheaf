# Combobox display label and submitted ID

Two paired Chromium cases passed 4/4 executions against actual Base UI object
items and LiveView string IDs with label metadata. United Kingdom displays for
the initial gb value. Typing Ind and selecting India by keyboard displays India
while submitting in through the named native form input. Escape after an edited
query restores United Kingdom while preserving gb.

The reference uses itemToStringLabel and itemToStringValue; the LiveView adapter
resolves labels from server-provided options. Object identity, unloaded selected
options and arbitrary object values are not certified by this small gate.
Raw report: `artifacts/label-combobox-paired-chromium.json`.
