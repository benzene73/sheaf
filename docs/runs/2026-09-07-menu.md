# Menu paired gate

The React fixture imports exact Base UI source at
`4d92faa1a4da6a5fe66a6194401470974fc2f8fe`. The LiveView target uses source-derived
list navigation, typeahead and activation decisions with an explicit native
popover integration layer. This is not a complete Menu/FloatingFocusManager port.

Final expanded matrix: **96/96 target executions passed**, sixteen scenarios
against both targets on Chromium 145, Firefox 146 and WebKit 26.

## Failures that drove corrections

The initial ten-scenario matrix returned 57/60: on every engine, a keep-open menu
action preserved item focus and accepted the action, but the LiveView patch reset
`aria-expanded` to false. The adapter now reasserts browser-owned open semantics
after server patches. Tests were retained unchanged.

Independent review added Space and Tab cases. A default Base UI menu blocks an
outside click through its backdrop, so the durable test uses a real pointer at
the underlying button's coordinates and asserts that its click counter remains
zero. Appending a new button after the portal is a different paint-order fixture
and was not treated as evidence for this normal composition.

An explicit `modal=false` case separately proves outside activation. Chromium and
Firefox focus the clicked button. Actual upstream WebKit activates the button
without focusing it and then restores trigger focus. The adapter initially left
focus on the body, producing 83/84; it needed the bounded return-focus fallback.
The suite records this engine-specific source observation and applies the same
expectation to both targets within each engine.

## Scope and reproduction

Sixteen shared scenarios cover opening arrows, direct looping, disabled item
highlighting, Home/End, repeated and multi-letter typeahead, Space while typing,
disabled activation refusal, Enter/Space activation, Escape, Tab and reverse Tab,
modal and nonmodal outside pointer policy, and keep-open action patches.

Run `BROWSERS=chromium,firefox,webkit node harness/menu.mjs` with both fixtures
running. Raw evidence includes `artifacts/menu-paired-matrix.json` (57/60),
`artifacts/menu-expanded-paired.json` (83/84), and
`artifacts/menu-final-paired.json` (final expanded run).

No claim is made for submenus, context menus, touch press-and-hold, nested focus
layers, full aria hiding, complete controlled state, item collection replacement,
or assistive technology. These remain distinct from the bounded passing paths.
