# Everyday Tabs gate

Six paired Chromium scenarios passed 12/12 target executions: pointer selection,
manual arrow focus and looping, Home/End, Enter/Space activation, automatic
activation, and panel/ARIA linkage with a single tab stop. Raw report:
`artifacts/tabs-paired-chromium.json`.

The actual upstream oracle corrected an initial test assumption: disabled tabs
are focusable, not skipped. ArrowRight focuses Disabled while Overview remains
selected; Enter does not activate Disabled. The next arrow focuses Reviews.
With activateOnFocus enabled, Disabled still cannot activate. Initial incorrect
expectations are visible in `artifacts/tabs-upstream.json`; corrected reference
cases passed 6/6 before the paired gate. Vertical orientation, RTL, cancellation,
dynamic tab removal and nested composites are outside this everyday slice.
